Rankings

1 Stacked List Recommended
Full-width cards with explicit checkboxes. Clearest affordance for multi-select. Scales well if options change.
+ Obvious multi-select (visible checkboxes). Easy to scan vertically. "Others" text input fits naturally inline. Matches FormSG's existing form field patterns.
- Takes more vertical space. Less visually distinctive than tiles.
2 Tile Grid
2x3 grid of equal tiles with icons. Visually bold and scannable. Matches Figma draft references (beehiiv, Copy.ai).
+ Compact layout. Visually appealing. Icons help quick recognition. Matches the Figma "possible future" draft.
- Multi-select less obvious without visible checkboxes. Harder to add descriptions per option. "Others" text input placement less natural.
3 Icon Chips
Horizontal pill-shaped chips. Casual, lightweight feel. Good for quick tagging.
+ Most compact. Feels fast and lightweight. Good for mobile.
- Least formal for an important data collection step. Multi-select less discoverable. Doesn't match FormSG's existing patterns. May feel too casual for a mandatory question.
